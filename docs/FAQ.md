# FAQ / 排错

## 启动相关

**Q: 双击 exe 报 `Could not create temporary directory!`**

单文件版启动时要把自身解压到 `%TEMP%` 再运行，被下列情况拦住就会这样：

- 安全软件（Defender 受控文件夹访问 / 360 / 火绒 / 企业 EDR）
- `%TEMP%` 路径不存在、无写权限、磁盘满
- 直接在压缩包内或网络共享上双击

改用**便携目录版**（不写临时目录）即可；或把 exe 放进可写目录并把该目录加杀软信任。

**Q: 只拷了 exe 到别处就打不开**

便携版的 `_internal\` 是运行时，必须和 exe 一起拷。要单文件就用 `qmc-unlock.exe`。

**Q: 首次启动慢**

单文件版要先解压 60+ MB，慢 3~5 秒属正常；便携版是秒开。

## key 相关

**Q: 列表里 key 列显示「缺」**

点「抓取缺失的 key」。需要本机装了 QQ 音乐，程序会自动启动它并逐个打开文件。

**Q: 抓 key 一直失败**

1. 确认 QQ 音乐能正常播放这首歌（客户端自己解得开，才有 key 可抓）
2. 安全软件可能拦截进程注入 —— 把程序目录加入信任，或临时关实时保护
3. 先在客户端里播一下该曲，再点抓取（key 在解密那一刻存在于内存）

**Q: 提示「抓到 key 但解不开」（key 不匹配）**

说明抓到的是别的歌的 key。确认一次只处理一首、且客户端确实打开了目标文件；
删掉对应 `.key` 重新抓。

**Q: 换电脑还能解吗**

能，只要 `data\ekeys\*.key` 跟着走（便携模式天然跟着文件夹）。
key 与账号无关、不过期，缓存后不需要联网也不需要客户端。

**Q: 可以让别人用我的 key 吗**

不建议 —— key 是本机抓的，也不该外传；让对方自己抓一次即可（几秒钟）。

## 解密相关

**Q: 解出来的文件末尾报 1 帧错误（invalid residual / invalid sync code / overread）**

QQ 音乐加密时在尾部加了 ≤9 KB 对齐填充，不属于音频。勾「解密后修尾」用 FFmpeg 无损重封装即可，
或命令行加 `--trim`。不处理也能正常播放，只影响最后一帧校验。

**Q: `--trim` 很慢**

修尾是 FLAC 解码 + 重新编码，192 kHz / 24 bit 的长曲目需要几十秒；只想要原始解密结果就别勾。

**Q: 解出来是噪声 / 打不开**

key 不对（见上）。也可能是文件不是音乐文件（例如封面缓存被改名）。

**Q: 支持 mgg 吗**

支持，输出 `.ogg`，同样需要 key（key 长度通常 ≤300，走 MapCipher）。

**Q: 老格式 qmc0 / qmc3 需要 key 吗**

不需要，走 QMCv1 固定表，插上就能解。

## 其它

**Q: 会修改我的 QQ 音乐吗**

不会。只读进程内存、不写客户端文件、不改配置；关掉程序即恢复原状。

**Q: 会上传什么吗**

不会。整个程序没有任何网络请求（`grabkeys` 也只是本地进程间通信）。

**Q: 支持 macOS / Linux 吗**

解密本身可以（把 `data\ekeys\*.key` 拷过去即可）；抓 key 需要 Windows 上的 QQ 音乐客户端。

**Q: 支持哪些音乐 App**

只做 QQ 音乐（QMC）。网易云 `.ncm`、酷狗 `.kgm`、酷我 `.kwm` 不在范围内。
